# Tony Festino

**Live:** _coming soon_ · **Code:** private

Website for Tony Festino, a party brand running private parties, house parties and club nights in Rome and Milan. Bilingual (Italian/English) and mobile-first.

## What it does

- **Next event up front:** a full-screen video hero with an LED-style ticker, a live countdown and the date and venue of the next party.
- **Events:** upcoming and past events with add-to-calendar, share and directions.
- **Gallery & clips:** a photo gallery with a lightbox and short video clips from past parties.
- **Instagram:** an embedded Instagram feed.
- **Private-party requests:** a form that turns the request into a ready-made WhatsApp or Instagram message.
- **Built-in admin panel:** the owners edit events, photos, videos and texts in both languages without touching code. Content lives in one JSON file.

## Stack

HTML · CSS · vanilla JavaScript (no framework, no build step) · JSON content model
