# bianchimino.com

**Live:** [bianchimino.com](https://bianchimino.com) · **Code:** private

My personal link hub and mini-portfolio: one page that gathers my profiles, contact links, resume and featured projects.

<!-- To add a screenshot: upload it to assets/bianchimino.png and put ![Screenshot](../assets/bianchimino.png) here -->

## What it does

- Links to LinkedIn, GitHub, Instagram, email, Telegram and my resume.
- Featured project cards (for example a closed-loop magnetic levitator).
- Light and dark themes, plus a built-in "tweaks" panel to adjust the look live.

## Stack

React 18 · Vite · custom CSS (Geist & JetBrains Mono) · Supabase · built with Lovable
